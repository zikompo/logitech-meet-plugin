# Google Meet (Node) plugin

Logi Actions plugin built on the Node.js SDK. See the [root README](../README.md) for setup, the Chrome extension it needs, and the action list.

- `index.ts`: registers actions and starts the bridge
- `src/bridge.ts`: WebSocket server on `127.0.0.1:47831` that the extension connects to
- `src/actions.ts`: one action per Meet command (icons in `package/actionicons`, generated by `../tools/make-icons.mjs`)
